eSC - Chess Club Manager

Documentație tehnică și raport arhitectural

Proiect PHP Monolitic (Fără JavaScript) - eSC

1. Introducere (Introduction)

eSC - Chess Club Manager este un sistem web dedicat administrării unui club de șah. Construit cu o arhitectură strict bazată pe PHP (fără utilizarea JavaScript pe partea de client), oferind suport complet pentru gestiunea membrilor, organizarea competițiilor, evidența antrenorilor, a sălilor de joc și chiar un modul integrat de rapoarte și deconturi financiare.

2. Scop și Funcționalitate (System Purpose and Functionality)

Sistemul facilitează digitalizarea unui club sportiv de șah. Interfețele și drepturile de acces diferă bazat pe tipul de utilizator:

  • Admin: Drepturi absolute. Poate crea membri, gestiona antrenori, administra competiții, verifica deconturi (Travel Expenses) și face importuri/exporturi agregate.
  • Antrenor (Coach): Are acces la proprii jucători, poate vedea și seta programele în săli și urmărește evoluția competițională a grupului său.
  • Membru (Member): Vizualizează propriul profil, activitățile clubului și scorurile/leaderboard-ul public.

3. Funcționalități Implementate (Implemented Features)

Platforma dispune de următoarele module cheie:

  • Sistem Gestiune (CRUD): Interfețe dedicate pentru manipularea entităților principale (members.php, coaches.php, rooms.php, activities.php, competitions.php). Include prevenție CSRF și input validation server-side.
  • Sistemul Financiar (Rapoarte Deplasări): Prin travel_expenses.php și travel_report.php se permit înregistrarea costurilor (transport, cazare, masă) și calculul totalului pentru deplasările la competiții.
  • Import / Export Date: Aplicația permite popularea bazei de date masiv via fișiere CSV (inclus în functions.php) și export avansat către XML (export_data_xml.php) și JSON (export_data_json.php) prin intermediul claselor native PHP (precum DOMDocument).
  • Microservicii și Notificări: Un endpoint dedicat api/stats.php furnizează statistici. Acest API este consumat de PHP pe post de client HTTP la randarea paginii prin plugin_notificari.php, generând automat un Toast de informare direct de pe server.
  • Istoric și Leaderboards: performance_history.php coroborează prezențele membrilor și generează un istoric clar pentru antrenori și jucători.

4. Arhitectura și Baza de Date (Architecture & Data Schema)

Aplicația urmează o arhitectură Software Monolitică Client-Server centrată pe execuție procesuală PHP.

Sistemul Bazei de Date (MySQL via PDO)

Managerul automatizat din schema.php garantează coerența bazei de date (MySQL). Tabelele interconectate prin Chei Străine (Foreign Keys) cu reguli de tip CASCADE sau SET NULL garantează integritatea referențială.

  • users - credentials asociate cu un id_membru / id_antrenor
  • members - entitățile cu nivel_joc și legătură către antrenor
  • competition_participants - tabelă pivot între competiții și membri
  • travel_expenses - raportări de costuri deplasări

5. Interfață și Responsivitate (UI and Interaction)

Interfața respectă constrângerile unei aplicații non-JavaScript. Responsivitatea (adaptarea la ecrane de telefon) pe navigare se face prin intermediul schemei "CSS Checkbox Hack" integrată în includes/header.php.

HTML-ul este curat, utilizând atribute ARIA, cu elemente semantice specifice (<header>, <nav>, <main>) asigurând o accesibilitate peste medie (a11y).

6. Glosar (Glossary)

  • PDO: PHP Data Objects - interfață sigură de comunicare cu SQL pentru evitarea injecțiilor de date.
  • CSRF Token: Cheie criptografică temporală ce asigură că o cerere POST originează legitim din formularul oficial al paginii.
  • CSS Checkbox Hack: Tehnică ce profită de pseudo-clasa :checked în CSS pentru a manevra vizibilitatea unui meniu drop-down, excluzând necesitatea codului JS.
